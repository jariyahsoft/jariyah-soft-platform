# TOR / Software Requirement Specification (SRS)

## โครงการ

Digital Software & Knowledge Platform

แพลตฟอร์มศูนย์กลางซอฟต์แวร์ องค์ความรู้ดิจิทัล และชุมชนนักพัฒนาซอฟต์แวร์สำหรับประชาชน

---

# 1. วัตถุประสงค์

1. เผยแพร่ซอฟต์แวร์ที่พัฒนาโดยคนไทยให้ใช้งานฟรี
2. ส่งเสริมการใช้เทคโนโลยีดิจิทัลอย่างถูกต้อง
3. เผยแพร่ความรู้ด้าน AI และเทคโนโลยีสารสนเทศ
4. สร้างชุมชนนักพัฒนาซอฟต์แวร์
5. สนับสนุนโครงการ Open Source
6. สร้างแหล่งเรียนรู้และพัฒนาทักษะดิจิทัลสำหรับประชาชน

---

# 26. User Stories & Acceptance Criteria

## Guest

### US-001 ดูรายการซอฟต์แวร์

As a Guest

I want to browse software

So that I can find software that meets my needs.

Acceptance Criteria

* แสดงรายการซอฟต์แวร์ทั้งหมด
* ค้นหาได้จากชื่อ
* กรองตามหมวดหมู่ได้
* เปิดหน้ารายละเอียดได้

---

### US-002 ดาวน์โหลดซอฟต์แวร์

As a Guest

I want to download software

So that I can use it immediately.

Acceptance Criteria

* ดาวน์โหลดได้โดยไม่ต้อง Login
* ระบบบันทึกจำนวน Download
* Redirect ไปยังแหล่งดาวน์โหลดที่กำหนด

---

## Developer

### US-101 ส่งซอฟต์แวร์เข้าระบบ

Acceptance Criteria

* กรอกข้อมูลครบถ้วน
* แนบ Logo ได้
* ระบุ License ได้
* ส่งเข้าสถานะ Submitted
* Moderator ได้รับ Notification

---

## Moderator

### US-201 อนุมัติซอฟต์แวร์

Acceptance Criteria

* ดูรายละเอียด Submission
* Approve / Reject ได้
* ระบุเหตุผลการ Reject ได้
* ระบบบันทึก Audit Log
